Opistophthalmus · omaflank fix2026-09-07

Flanks rebuilt with the real, tested tools

The earlier oma alignments used the wrong MAFFT parameters and no flank post-processing. This rebuild runs the project's own justify_all.py and trim_flanks.py (de-gap and justify, then cap column width so one long-flanked outlier stops padding every other copy) and its own newsp_all.island_scan for flank uniqueness — the same calibrated tool used on the pom/aca/hyd candidates, with the same thresholds (clean ≤ 0.067, borderline ≤ 0.19, caution ≤ 0.37, else reject band). Nothing here is a new algorithm; the only new code is a naming adapter and a cosmetic case pass to restore the lowercase-flank display convention that justify_all's numeric round-trip drops.
